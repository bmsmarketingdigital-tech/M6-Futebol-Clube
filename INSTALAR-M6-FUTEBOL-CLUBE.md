# Instalação da Escola de Futebol M6 Futebol Clube

1. Copie `M6FutebolClube-Setup-1.0.0.exe` para o computador da escolinha.
2. Feche versões anteriores do sistema e execute o instalador.
3. Se o Windows exibir o SmartScreen, escolha **Mais informações** e depois **Executar assim mesmo**. Esta primeira versão ainda não possui certificado de assinatura digital.
4. Abra o atalho **Escola de Futebol M6 Futebol Clube** criado na área de trabalho.

Na primeira abertura, aguarde até 30 segundos para a preparação do sistema local. As próximas aberturas serão mais rápidas.

## Conectar o WhatsApp

1. Abra **QR e entrada** no sistema.
2. Clique em **Conectar WhatsApp**.
3. No celular da escolinha, abra o WhatsApp e acesse **Aparelhos conectados** > **Conectar aparelho**.
4. Leia o QR Code mostrado no sistema.
5. Aguarde o status mudar para **Conectado**.

O envio não cobra por mensagem, pois utiliza a sessão do WhatsApp Web. Essa integração não é uma API oficial do WhatsApp e pode exigir uma nova leitura do QR Code caso a sessão seja encerrada.

## Dados e requisitos

- O computador precisa ter Google Chrome ou Microsoft Edge instalado.
- Os dados, a sessão do WhatsApp e os registros ficam em `C:\ProgramData\M6FutebolClube`.
- A desinstalação não apaga automaticamente esses dados.
- Faça cópias de segurança periódicas da pasta `C:\ProgramData\M6FutebolClube`.
